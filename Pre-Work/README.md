# Pre-Work

This folder is your starting point. Before diving into machine learning theory, you need two things: comfort with Python and a sense of what ML actually looks like in practice. These notebooks give you both.

---

## What you'll learn

### Python fundamentals
The two intro notebooks walk you through the building blocks of the language — variables, data types, lists, loops, conditionals, and functions. Everything you write in every other notebook in this course depends on these concepts.

- `Hands_on_notebook_introduction_to_Python.ipynb` — core syntax and data types
- `Python_PreWork_Session.ipynb` — same concepts applied to a real business scenario (automobiles)

### Applied AI case studies
These three notebooks show you finished ML projects from start to finish. You don't need to understand every line yet — the goal is to build intuition for what the workflow looks like before you study the pieces individually.

- **Hotel Booking Cancellation** (`Hotel Booking Cancellation Prediction/`) — a classification problem: predict which hotel reservations will be cancelled. Uses decision trees and random forests.
- **COVID Detection** (`COVID Detection/`) — a computer vision problem: classify chest X-rays as COVID-positive or negative using a convolutional neural network. Includes a Gradio interface for interactive predictions.
- **Airline Customer Sentiment** (`Airline Customer Sentiment Analysis/`) — a text analysis problem: determine whether customer reviews about an airline are positive or negative.

### Calling an AI API
- `openai_api_demo.ipynb` — shows how to send prompts to a language model and work with the response programmatically. A useful reference once you start building AI-powered tools.

---

## Suggested order

1. `Hands_on_notebook_introduction_to_Python.ipynb`
2. `Python_PreWork_Session.ipynb`
3. Any of the three case study notebooks — they're independent, pick whichever domain interests you most
4. `openai_api_demo.ipynb`

---

## Key takeaway

ML projects follow a repeating pattern: load data → explore → clean → model → evaluate → interpret. You'll see this loop in every case study here. Keep it in mind as you work through the rest of the course.
